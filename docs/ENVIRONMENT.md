# 9. Environment / login / session

> ค่าจริงของ env Pyrite (URL · VPN · auth flow · บัญชีเทส) ยังไม่ได้ยืนยัน — กรอกใน `references/pyrite-project-guide.md` เป็น `{PLACEHOLDER}` และเก็บค่าจริงที่ `~/.pyrite-qa-secrets/` เท่านั้น

- ยืนยัน env + account กับ user ก่อนเทสทุกครั้ง ห้ามเลือกเอง · ระบุแล้วในรอบ = แจ้งแล้วใช้เลย
- เครื่องมือที่เลือก env ห้ามมีค่าเริ่มต้น · ค่าปลายทาง/ตัวตนต้องมีชื่อ env ในตัว · คำสั่งที่ยกให้คนอื่นรัน ต้องเทียบ env ก่อนส่ง
- env ที่เจ้าของงานยังไม่อนุญาต = ห้ามแตะ (ไม่สแกน ไม่เขียน ไม่ probe) · production เขียนได้เฉพาะเมื่อได้อนุมัติเป็นรายกรณี
- agent ห้ามพิมพ์รหัสผ่านทุกบัญชี · ใช้ saved session ที่คนล็อกอินให้ · รหัสผ่านในคำสั่งใช้ `read -rs`
- หยุดโปรเซสด้วย pid ที่รู้ที่มาเท่านั้น ห้าม `pkill -f`/`killall` เมื่อมีตัวจริงรัน
- ข้อมูลบัญชีอ้างจากชีทบัญชีของรอบเท่านั้น ("ไม่มี session" ≠ "ไม่มีบัญชี")
- probe เครือข่าย/env ตัดสินจากรหัสจบของ curl ห้ามเทียบสตริง `-w %{http_code}` กับ `"000"` · gate ทุกตัวต้องมีเทส known-negative
- สั่ง `playwright test` ด้วยมือ: รัน `--list --reporter=json` ด้วย argv เดียวกันก่อน แนบจำนวนเทสต์
- เครื่องมือ/ตัวรันทดสอบด้วยงานจริงที่รู้ผล ไม่ใช่ `--version`
