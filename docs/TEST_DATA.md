# 11. Test data

> ขั้นตอนเตรียม test data ของ Pyrite ยังไม่ได้กำหนด — ถามเจ้าของงานก่อนสร้างข้อมูลบน env ใดๆ และบันทึกขั้นตอนที่ยืนยันแล้วไว้ที่นี่

- ชื่อ+คำอธิบายของ test data เป็นเนื้อหาจริง: ห้าม QA/test/ทดสอบระบบ/placeholder/dummy · ห้ามวงเล็บสถานะท้ายชื่อ · ชื่อซ้ำ = หยุดแจ้ง user ก่อน
- ข้อมูลที่สร้างเพื่อทดสอบต้องลบให้หมดเมื่อจบ ถ้าเจ้าของงานไม่ได้สั่งให้เก็บ
- ห้ามเขียนข้อมูลบน env ที่ไม่ได้อนุญาต (ดู `docs/ENVIRONMENT.md`)
