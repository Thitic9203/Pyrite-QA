## สรุปสั้น (Executive Summary)

ก่อน push ครั้งแรก ผมกวาดหาชื่อลูกค้าใน history ด้วย `git log -p --all | grep -c …` แล้วได้ 0 จึงรายงานว่า history สะอาด 0 จุด
แต่ hook ของ rtk เปลี่ยน `git log` เป็น `rtk git log` ซึ่งย่อผลลัพธ์ (ตัดบรรทัด header เช่น `Author:` ออก) ตัววัดจึงไม่ได้อ่าน history ครบ
รอบ catch-ai วัดใหม่ด้วย `rtk proxy git log -p --all` (ไม่ย่อ) เจอ 4 บรรทัด ทั้งหมดเป็นบรรทัด `Author:` ที่มีอีเมลผู้ commit ส่วนชื่อลูกค้ายังเป็น 0
แก้ด้วยกฎ: งานตรวจ history/diff ต้องใช้ `rtk proxy git …` และตัววัดต้องผ่านตัวอย่างที่รู้คำตอบก่อน

---

## 1. ปัญหา (Problem Statement)

- ผลแรก (ผ่าน rtk): `git log -p --all | grep -c -i -E '…|skilllane'` → `0`
- ผลใหม่ (ไม่ย่อ): `rtk proxy git log -p --all` → 25118 บรรทัด, ตรง pattern 4 บรรทัด คือบรรทัด `Author:` ของ 4 commit
- pattern เดียวกันมีคำที่อยู่ในอีเมลผู้ commit จริง ถ้าตัววัดอ่านครบต้องได้ ≥1 — ผล 0 จึงพิสูจน์ว่าตัววัดไม่ได้อ่านครบ

**สิ่งที่ควรจะเป็น:** `CLAUDE.md` §0 "เครื่องมือวัดที่เขียนเองต้องผ่านตัวอย่างที่รู้คำตอบ (ต้องพบ 1 · ต้องไม่พบ 1) ก่อนเชื่อ" และ "บรรทัดสรุปของเครื่องมือไม่ใช่คำตอบจนพิสูจน์ว่าวัดสิ่งเดียวกัน"

## 3. สาเหตุโดยละเอียด (Root Cause Analysis)

### 5 Whys

1. **ทำไมผลวัดเป็น 0?** — เพราะ grep อ่านผลของ `git log` ที่ถูกย่อ ไม่มีบรรทัด `Author:`
2. **ทำไมถูกย่อ?** — เพราะ hook ของ rtk เปลี่ยนคำสั่ง git ใน Bash เป็น `rtk git` โดยอัตโนมัติ
3. **ทำไมไม่รู้ว่าถูกย่อ?** — เพราะการเปลี่ยนคำสั่งเกิดเงียบๆ และผลออกมาเป็นตัวเลขที่ดูสมเหตุสมผล
4. **ทำไมเชื่อตัวเลขนั้น?** — เพราะไม่ได้ทดสอบตัววัดกับตัวอย่างที่รู้คำตอบ (คำที่รู้ว่ามีใน history ต้องได้ ≥1)
5. **ทำไมไม่ทดสอบ?** — เพราะไม่มีกฎในระดับ repo ที่ชี้ว่า rtk เปลี่ยนผลของ git ในงาน audit — มีแต่กฎทั่วไปเรื่อง known-answer ซึ่งผมไม่ได้ทำตาม

**ทำไมชั้นป้องกันที่มีอยู่ถึงไม่จับ:** ไม่มีชั้นอัตโนมัติไหนตรวจการกวาด history · `check-no-secrets.sh` ตรวจไฟล์ใน tree ไม่ได้ตรวจ metadata ของ commit

## 5. แนวทางการแก้ไข (Fix)

- วัดใหม่ด้วย `rtk proxy git log -p --all` แล้วอ่านทุกบรรทัดที่ตรง pattern
- เรื่องอีเมลผู้ commit ส่งเป็นคำถามให้เจ้าของงานตัดสิน (repo พี่น้อง ols-qa และ helix ใช้แบบเดียวกัน)

**ยืนยันแล้วด้วย:** `rtk proxy git log -p --all | grep -n -i -E '<OLS_CUSTOMER_TERMS>'` → 0 บรรทัด
